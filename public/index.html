Mac/Linux: the official MetaTrader5 python package is Windows-only at the protocol level; run MT5 under Wine or a Windows VM, then the same bridge script inside that environment.

Quant Lab Personal quant engine

Your personal quant, grounded in real formulas

This is a rule-based financial engineering engine — Sharpe/Sortino/Calmar ratios, drawdown, VaR/CVaR, correlation, and Kelly sizing are computed with correct, standard formulas directly from your actual trade history. It is not a trained model and does not backtest against real historical market data — there's no live data feed or ML training pipeline reachable from inside this app. The lifecycle tracker below (Hypothesis → Data → Backtest → Validate → Deploy) is a structured workspace for your own research process, with backtests running against this app's synthetic price simulation, clearly labeled as such. An optional LLM layer can discuss concepts and your numbers conversationally, grounded in what's actually computed.
